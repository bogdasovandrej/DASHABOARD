# Тренировка на время

Это репетиция финала на 60 минут. Данные и анкета незнакомые, файла сопоставления вопросов нет: его нужно сделать самим.
Папку `proverka` до конца тренировки не открывать, там ответы.

## Легенда

Вы на финале. Организаторы выдали:

- `otvety.xlsx`: выгрузка из сервиса анкет, два листа: «Стажёры» и «Наставники»;
- `anketa.md`: вопросы обеих анкет и шкалы.

В программе 30 стажёров, идёт пятый месяц из шести. Команда молодёжных программ просит:

1. Показать общую картину по программе.
2. Назвать стажёров, которым нужно внимание на этой неделе, и объяснить причину.
3. Предложить, что с каждым делать.
4. Найти хотя бы одну проблему, которая касается не одного стажёра, а подразделения или наставника.

## Что нужно сделать

1. Составить свой файл сопоставления вопросов. Начните с копии нашего: в папке `dashboard` выполните

```
copy survey\questions.csv survey\questions_tren.csv
```

   и перепишите строки под новую анкету. Как заполнять колонки, написано в `dashboard/README.md`, раздел «Если анкета другая».

2. Запустить дашборд с этим файлом и отдельной базой (PowerShell, папка `dashboard`):

```
$env:QUESTIONS_CSV="survey/questions_tren.csv"; $env:DB_PATH="data/tren.db"; streamlit run app.py
```

3. В разделе «Данные» загрузить оба листа: сначала «Стажёры», потом «Наставники». Посмотреть, какие колонки дашборд не узнал.

4. Проверить себя. В том же окне PowerShell остановите дашборд (Ctrl+C) и выполните

```
python ..\trenirovka\proverka\proverit.py
```

   Скрипт покажет, что загрузилось верно, а что нет, с подсказками. Исправьте файл, очистите базу в разделе «Данные», загрузите заново.

5. Подготовить защиту на две минуты: три находки из данных и что с ними делать HR.

## Расписание

| Время | Что делаем |
|---|---|
| 0:00-0:10 | Читаем легенду и анкету, открываем выгрузку, делим работу |
| 0:10-0:30 | Файл сопоставления, первая загрузка |
| 0:30-0:40 | Самопроверка, исправления |
| 0:40-0:50 | Три находки, скриншоты |
| 0:50-1:00 | Рассказ на две минуты вслух, по таймеру |

## Кто что делает

- Один человек ведёт файл сопоставления.
- Второй открывает выгрузку и ищет странности: названия колонок, шкалы, пустые строки, как записан месяц.
- Третий запускает дашборд, загружает данные, читает сообщения об ошибках.
- Четвёртый с самого начала пишет рассказ для защиты и следит за временем.

## Правила

- Пользоваться ИИ можно, как и на финале.
- Код дашборда менять можно, но сначала попробуйте обойтись файлом сопоставления.
- Засеките время. Если не уложились в час, запишите, на чём застряли: это главный результат тренировки.

## После тренировки

Сравните со своим результатом и запишите три вывода: что сделаем по-другому на финале.
