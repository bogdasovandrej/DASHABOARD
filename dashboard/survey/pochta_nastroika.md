# Как подключить ответы из Яндекс Форм через почту

Форма после каждого заполнения шлёт письмо на твою почту Яндекса. Дашборд раз в минуту заходит в ящик,
находит письма с меткой `[intern]` или `[mentor]` в теме и забирает из них ответы. Почту дашборд только читает,
ничего в ящике не удаляет и не помечает.

## 1. Включить доступ к почте для программ

1. Открой mail.yandex.ru → шестерёнка → «Все настройки» → «Почтовые программы».
2. Поставь галочку «С сервера imap.yandex.ru по протоколу IMAP».
3. Способ авторизации — «Пароли приложений и OAuth-токены». Сохрани.

## 2. Создать пароль приложения

1. Открой id.yandex.ru → «Безопасность» → «Пароли приложений».
2. «Создать пароль» → тип «Почта» → название, например, «Дашборд стажировок».
3. Скопируй пароль (он показывается один раз).
4. Открой Блокнотом `C:\Users\bogda\Dashaboard\dashboard\.env` и заполни две строки внизу:
   ```
   YANDEX_MAIL=твой_адрес@yandex.ru
   YANDEX_APP_PASSWORD=скопированный_пароль
   ```
   Пароль никому не пересылай и в чат не вставляй. Файл `.env` в git не попадает.

## 3. Настроить письмо в анкете стажёра

Форма: https://forms.yandex.ru/admin/6afb375b90290223d2c3f6fe/edit → вкладка «Интеграции».
Там уже есть группа действий с действием «Почта».

1. «Кому» — оставь «Почта автора формы».
2. «Тема» — сотри всё и впиши: `[intern] Ответ на анкету`
3. «Текст» — вставь переменную «Ответы на вопросы в виде json». В её настройках открой «Вопросы»,
   нажми «Выбрать все» и «Сохранить». Без выбранных вопросов Яндекс не сохраняет действие.
4. Включи переключатель у действия «Почта» (справа от заголовка).
5. Нажми «Сохранить» внизу действия.

## 4. То же в анкете наставника

Форма: https://forms.yandex.ru/admin/6afc661cba5f0233e5bffc38/edit → «Интеграции».
Всё так же, только тема: `[mentor] Ответ на анкету`

## 5. Проверка

25.11.2026 обе почтовые интеграции уже настроены и включены. По одному контрольному ответу с именем
«ТЕСТ Интеграция 25.11» от каждой роли дошло до почты в JSON. Это проверка доставки формы до ящика.
Чтобы проверить импорт в карточку, нужен пароль приложения из раздела 2 и временная база.

1. Запусти дашборд (`zapusk.bat`).
2. Заполни анкету стажёра: https://forms.yandex.ru/u/6afb375b90290223d2c3f6fe/
3. Подожди до минуты. Внизу левой панели дашборда будет «Почта проверена в …, новых ответов: 1»,
   а стажёр появится в ленте. Можно не ждать: «Данные» → «Проверить почту сейчас».
