# Настройка 2 новых Яндекс Форм по финальной структуре МГТС (5 минут, без slug!)

Код в `core/mail.py` теперь **сам понимает стандартное письмо Яндекс Форм** («Ответы на вопросы» в виде `Название поля: Значение`), поэтому никакие технические `slug` прописывать не нужно!

## Форма 1 — Пульс-опрос стажёра
Создай новую форму на https://forms.yandex.ru/admin/ с **точными названиями вопросов**:
1. `ID стажера` *(короткий текст, обязательный — пример: СТ-006)*
2. `Подразделение / направление стажировки` *(выпадающий список или короткий текст: Технический блок, Коммерческий блок, Административный блок, HR-блок, IT)*
3. `Контрольный период` *(список: Месяц 1, Месяц 2, Месяц 3, Месяц 4, Месяц 5, Месяц 6)*
4. `Понятность задач` *(выбор 1, 2, 3, 4, 5)*
5. `Поддержка и обратная связь наставника` *(выбор 1, 2, 3, 4, 5)*
6. `Комфортность нагрузки` *(выбор 1, 2, 3, 4, 5)*
7. `Интерес к задачам` *(выбор 1, 2, 3, 4, 5)*
8. `Профессиональное развитие` *(выбор 1, 2, 3, 4, 5)*
9. `Взаимодействие с командой` *(выбор 1, 2, 3, 4, 5)*
10. `Общая удовлетворенность стажировкой` *(выбор 1, 2, 3, 4, 5)*
11. `Сложности за период` *(длинный текст, необязательный)*
12. `Что мешает работать и развиваться` *(длинный текст, необязательный)*

**Вкладка «Интеграции» → «Почта»:**
- Кому: `Email автора формы` (твоя почта из `.env`)
- Тема: **`[intern] Ответ на анкету`**
- Текст: вставь переменную **`Ответы на вопросы`** (стандартную, НЕ JSON — выбери все вопросы) + по желанию строку `SEC=[Время заполнения в секундах]`.
- Включи переключатель и нажми **«Сохранить»**.

## Форма 2 — Анкета наставника
Создай вторую форму с **точными названиями вопросов**:
1. `ID наставника` *(короткий текст, обязательный — пример: Н-006)*
2. `ID стажера` *(короткий текст, обязательный — пример: СТ-006)*
3. `Подразделение / направление стажировки` *(список: Технический блок, Коммерческий блок, Административный блок, HR-блок, IT)*
4. `Контрольный период` *(список: Месяц 1 .. Месяц 6)*
5. `Понимание задач и ожиданий` *(выбор 1, 2, 3, 4, 5)*
6. `Качество выполнения задач` *(выбор 1, 2, 3, 4, 5)*
7. `Самостоятельность` *(выбор 1, 2, 3, 4, 5)*
8. `Соблюдение сроков и организация работы` *(выбор 1, 2, 3, 4, 5)*
9. `Вовлеченность и инициативность` *(выбор 1, 2, 3, 4, 5)*
10. `Взаимодействие с наставником и командой` *(выбор 1, 2, 3, 4, 5)*
11. `Комментарий о работе за период` *(длинный текст, необязательный)*
12. `Сложности / ситуации для внимания` *(длинный текст, необязательный)*

**Вкладка «Интеграции» → «Почта»:**
- Кому: `Email автора формы`
- Тема: **`[mentor] Ответ на анкету`**
- Текст: переменная **`Ответы на вопросы`** (выбери все вопросы).
- Включи переключатель и нажми **«Сохранить»**.

## Быстрая проверка живого сценария (для видео и защиты!)
1. Заполни Форму 1 за `СТ-006` (`IT`, `Месяц 6`, оценки `2, 2, 2, 3, 3, 3, 2`, комментарий: *«Высокая нагрузка, не хватает регулярной обратной связи от наставника»*).
2. В дашборде открой «Данные» → нажми **«Проверить почту сейчас»** (или подожди до 60 сек).
3. На «Обзоре» (Месяц 6) сразу появится **`СТ-006`**:
   - В таблице статуса: `Опрос стажёра: Сдал`, `Опрос наставника: Нет ответа`!
   - В светофоре: **🔴 Критичный сигнал**, точная цитата от GigaChat-2-Pro и готовое действие HR!
4. Затем заполни Форму 2 за `Н-006` → `СТ-006` (`Месяц 6`, оценки `4, 4, 3, 4, 4, 4`) — и на карточке сразу появится **расхождение взглядов** стажёра и наставника!
